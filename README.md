# Wayne Sims Plumbing – Website

Static, dependency-free website (HTML, CSS, JS). No build step.

## Run locally
Open `index.html` in a browser, or serve the folder:

    python3 -m http.server 8000

## Deploy
Upload the whole folder to any static host (Netlify, Vercel, Cloudflare Pages, GitHub Pages, or regular web hosting).

## Structure
- `index.html` – single-page site (hero, services, why us, team, contact)
- `css/styles.css` – all styling, responsive
- `js/main.js` – mobile menu, footer year
- `images/` – photos used on the site
- `favicon.svg`
